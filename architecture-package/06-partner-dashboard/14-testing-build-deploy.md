## Deploy
- **Vercel:** `apps/partner-dashboard/vercel.json` (framework nextjs; `buildCommand: cd ../.. && pnpm turbo run build --filter=@c1rcle/app-partner-dashboard`; `installCommand: cd ../.. && pnpm install --frozen-lockfile`; `outputDirectory: .next`; `github.silent`). The production branch of this project is `staging`. The README says Root Directory is `apps/partner-dashboard` with "include files outside root" enabled. Dev subdomain `staging.thec1rcle.com` is bound to this project (Preview, behind Vercel SSO).
- **Docker** (`apps/partner-dashboard/Dockerfile`): `node:22.22.2-alpine`, `turbo prune --docker`, build args `API_BASE_URL`, `APP_NAME`, `APP_ID` (default `partner`), `ENVIRONMENT`; runtime non-root `nextjs` user on 3001 running `apps/partner-dashboard/server.js`. **No Firebase build args**, so phone verification is unconfigured in Docker images. Not confirmed to be used in deployment.
- **Dependencies on the backend:** the direct-Bearer path needs gateway CORS (`ALLOWED_ORIGINS`) to include the dashboard origin and CSP `connect-src` to include the gateway origin. Backend on Render free tier cold-starts in 30–40 s; the first dashboard load after idle can appear stuck on the "Authorizing Access" screen.
