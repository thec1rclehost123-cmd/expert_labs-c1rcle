## Build and deploy
Vercel project for the admin console builds from production branch `main` (see `../11-infrastructure-and-cicd`); dev subdomain `admin.thec1rcle.com` is bound to Preview on `staging` behind Vercel SSO; a Docker image exists but its use is unconfirmed. Backend deploys via CI to Render on `staging` pushes. The console needs gateway CORS (`ALLOWED_ORIGINS`) to include its origin because it calls the gateway cross-origin with a Bearer token, and `GATEWAY_READINESS_TOKEN` set on the server for the Health page (without it the version call shows "unavailable"). Render free tier cold-starts in 30–40 s, so the first admin load after idle can look stuck.
Backend env names relevant to admin: `PAYOUTS_ENABLED`, `ALLOWED_ORIGINS`, `CORS_ALLOWED_ORIGINS`, `BETTER_AUTH_*`, `RAZORPAY_*`, `ENCRYPTION_KEY`, `ENCRYPTION_SALT`, `NGINX_READINESS_TOKEN`, `FIREBASE_*`, `RESEND_API_KEY`. Seed admin: `pnpm --filter api-gateway seed:admin`.
